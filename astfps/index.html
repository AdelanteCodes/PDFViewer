AstFPS.

A Minecraft optimization project focused on rendering, memory, and game logic. Built for Minecraft Java clients.

In developmentFabric · Java 26.3Free

A smoother world, in progress.

Rendering

Immediate rendering optimizations and an original experimental terrain submission stage. Sodium is not required.

Memory & game logic

Bundled optimization modules, optional terrain pregeneration, and opt-in local diagnostics.

Current development snapshot: 0.4.0-dev.3. Compilation and archive checks passed. Gameplay compatibility and performance gains remain unverified; 5× FPS is a target, not a measured result. Bundled modules retain their authors and licenses.
