Useful tools. Clear limits.

Complete means the described operation is implemented, not that it supports every possible PDF or matches every Sejda behavior. Limited features have intentional fidelity or document restrictions. All document processing runs on your device.

This is PDF Viewer 0.5 for the browser. Desktop browser flows have been checked in the available browser. Physical Android, iPhone Safari, Windows Chrome and Edge release checks remain pending; responsive layouts alone do not establish device compatibility.

Workspace, editing and extraction

FeatureStatusBehavior and limits
Search, categories, recent toolsCompleteRecent tool IDs are saved locally. Document bytes are not.
Document session, preview, undo/redoCompleteSix document versions maximum, with a 180 MiB history budget. A single larger document retains only its current version. Reload clears history.
PDF workflowsLimitedUp to 20 compatible PDF steps. Exports, password operations and image watermark assets are excluded from saved workflows. Completed steps remain after cancellation; bounded Undo can revert them.
Added text, images, markup, signatures, formsComplete within stated scopeVisual signatures only. Standard PDF fonts have limited script support. Added objects can be moved, resized and aligned.
Reusable stampsComplete within stated scopeSave image or text stamps in this browser. Saved cards restore automatically; click a card, then place once. Drag/resize the selected stamp, or right-click for Delete. New stamp annotations remain editable after export/reopen. Saved names and text/image assets can be updated. Includes APPROVED, PAID, DRAFT and RECEIVED presets. Up to 30 stamps / 50 MiB total. Clearing site data removes the library; PDFs are not cached.
Existing web link editingLimitedUpdate HTTP/HTTPS targets using the page link inspector. Internal destinations are retained. Link target updates are outside object undo/redo history.
Permanent redactionLimitedAffected pages are rebuilt as images. Original selectable text and links on these pages are lost; existing forms throughout the document flatten. Whiteout is a visual cover and does not remove underlying data.
Native existing text editingLimitedMuPDF removes original horizontal text spans; replacement text remains selectable. Original embedded font glyphs are reused; standard PDF faces retain their family/style. Missing replacement glyphs stop export; choose a fallback explicitly. No paragraph reflow. Scans need OCR first; rotated/skewed text and unusual encodings may be unsupported. Review surrounding content before export.
Arbitrary original image/object editing and paragraph reflowPendingAdded images/stamps can be moved and resized. Existing arbitrary image objects and full word-processor layout reflow are not yet supported.
AWB and airline billingLimitedExisting specialized parsers retained. Unfamiliar layouts and OCR need review. Page references and full text remain available.
Custom extraction mappings and correctionsLimitedLiteral same-line labels, per-page values, text or plain numbers, missing-value warnings. Save one mapping locally without document data. Enable corrections before editing exported values.
Excel combiningComplete within stated scopeHeading alignment, column mapping, previews, source columns and optional duplicate removal. Cached formula values only; formatting, macros, formulas, charts and links are not preserved.
Accurate editable Office conversionPendingCurrent Word exports use text flow; PowerPoint exports use page images. Complex layout reconstruction is not provided.
Cloud drives, hosted sharing, accounts, URL-to-PDFOutside this releaseNo processing backend or document upload service. Local HTML text conversion is available.
