Click to place text, comments or images. Drag to draw or size a shape, link, form field or redaction. Select an added item to move it, drag its lower-right handle to resize, or use the alignment controls. On phones, draw with one finger. Whiteout only covers content. Redaction rebuilds affected pages as images and flattens existing form fields throughout the document. Native text editing removes original glyphs and adds selectable replacement text with the original font when its glyphs are available. Redacted pages lose selectable text and existing links. Drawn or typed signatures are visual signatures, not certificate signatures.

Find and replace text

Replacement removes the original text spans and adds selectable text using each span’s original font when its glyphs are available. It does not reflow surrounding content. Check each replacement in the preview.

Fill existing form fields

Field values are applied when you download. Use PDF tools → Flatten form fields to make them read-only afterward.
