Files stay on this device. Use a PDF up to 100 MiB. For an encrypted file, use Unlock with password in PDF tools first.

Click to place text, comments or images. Drag to draw or size a shape, link, form field or redaction. Select an added item to move or resize it. On phones, draw with one finger. Whiteout only covers content. Redaction and replacement rebuild affected pages as images and flatten existing form fields throughout the document. Affected pages lose selectable text and existing links. Drawn or typed signatures are visual signatures, not certificate signatures.

Find and replace text

Replacement rebuilds affected pages as images, removing their original text. It does not reflow surrounding content. Check each replacement in the preview.

Fill existing form fields

Field values are applied when you download. Use PDF tools → Flatten form fields to make them read-only afterward.
